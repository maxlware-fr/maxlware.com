Référence API_

Documentation complète de l'API REST Maxlware. Base URL : https://api.maxlware.com/v1

Aperçu

L'API Maxlware est une API REST retournant du JSON. Elle est utilisée par le site principal, le dashboard interne et les projets associés.

PropriétéValeur
Base URLhttps://api.maxlware.com/v1
Formatapplication/json
AuthBearer token (header Authorization)
CORSOrigines autorisées explicitement
HTTPSObligatoire
⚠ CORS
Les requêtes avec credentials: 'include' nécessitent que ton origine soit explicitement autorisée côté serveur. * ne fonctionne pas avec les credentials.

Notification

Endpoint public permettant d'afficher une bannière de notification dynamique sur le site.

GET /com/notification Récupérer la notification active

Retourne la notification en cours si elle est activée. Aucun token requis.

Réponse 200

{
  "actived": "true",
  "message": "Le site sera en maintenance dimanche de 14h à 16h.",
  "autor": "Maxlware",
  "marker": "warn"
}

Champs

ChampTypeValeurs possibles
activedstring"true" / "false"
messagestringTexte affiché
autorstringAuteur optionnel
markerstringverified · warn · alert
ℹ Polling
Le site principal poll cet endpoint toutes les 5 minutes et n'affiche la bannière que si actived === "true". La fermeture est mémorisée dans localStorage pendant 24h.

Contact

Endpoint permettant de soumettre un message via le formulaire de contact du site.

POST /com/contact Envoyer un message de contact

Body (JSON)

ChampTypeDescription
namestringrequisNom de l'expéditeur
emailstringrequisAdresse email
messagestringrequisCorps du message
subjectstringoptionnelSujet du message

Réponse 200

{ "status": "ok", "message": "Message envoyé." }
ℹ Email
Les messages sont transmis via Mailtrap SMTP et visibles dans le dashboard interne.

Statuts

GET /status État des services
