Changelog_

Toutes les modifications notables apportées aux projets Maxlware, dans l'ordre chronologique inverse.

ℹ Convention
Les versions suivent SemVer : MAJEUR.MINEUR.PATCH. Les breaking changes sont marqués break.
v1.2.0 Majeur
Mars 2026
  • NEW Sections Projets, Stack et CTA ajoutées au site principal.
  • NEW Scroll reveal avec IntersectionObserver sur toutes les sections.
  • NEW Pages de documentation (docs/) avec design unifié.
  • FIX Flèche ↓ animée dans le hero pour inviter au scroll.
  • FIX Partenaires diapo : transition opacity corrigée sur mobile.
v1.1.0 Mineur
Janvier 2026
  • NEW Dashboard interne (interne.maxlware.com) avec authentification Bearer.
  • NEW Endpoint GET /admin/contact/messages pour la liste des contacts.
  • FIX CORS : remplacement de allow_origins=["*"] par des origines explicites.
  • FIX Dépendance FastAPI verify_any_auth ajoutée pour les routes admin.
  • FIX Mismatch token interne / admin résolu (format Bearer unifié).
v1.0.0 Stable
Novembre 2025
  • NEW Mise en ligne officielle de maxlware.com.
  • NEW API v1 déployée sur api.maxlware.com.
  • NEW Système de notification dynamique (/com/notification).
  • NEW Formulaire de contact avec Mailtrap SMTP.
  • NEW Easter egg clavier activé par la séquence adam.
  • NEW Diapo de partenaires (rotation toutes les 3 secondes).
  • NEW Badge statut en temps réel via statuts.maxlware.com.
v0.9.0 Bêta
Septembre 2025
  • NEW Prototype initial du site — design terminal sombre.
  • NEW BrawlBoost Discord bot — commandes slash, modals, persistence JSON.
  • NEW Script GTFS Node.js pour le calcul d'itinéraires de bus.
  • FIX Bot Discord : token invalide après rotation — résolu via Privileged Gateway Intents.
  • DÉPR Ancien système de notifications statiques remplacé par l'API dynamique.
