Présentation

EcoleDirecte App est une application desktop développée par Maxlware permettant d'accéder aux services EcoleDirecte sans navigateur web. L'objectif est d'offrir une expérience plus rapide, plus propre et plus personnalisable que le site officiel.

Le projet répond à un besoin simple : EcoleDirecte est lent, encombré de publicités et peu ergonomique. Une app native permet de contourner ça.

● Windows (en cours) ● macOS (en cours) ○ Linux (prévu)

✉️

Lecture et envoi de messages internes EcoleDirecte.

Accès aux devoirs et au cahier de texte par matière.

🔔

Notifications système lors de l'ajout d'une nouvelle note ou d'un message.

🌙
Thème sombre

Interface entièrement en dark mode, cohérente avec l'écosystème Maxlware.

Installation

L'installateur n'est pas encore disponible. Les étapes ci-dessous reflètent le process de développement local.

Prérequis

  • Python 3.10+
  • Node.js 18+ et npm
  • Un compte EcoleDirecte valide

En mode développement

  1. Cloner le dépôt
    git clone https://github.com/maxlware-fr/Unnoficial-EcoleDirectePlus.git
cd ecoledirecte-app
  2. Installer les dépendances Electron
    npm install
  3. Lancer l'application
    npm start

API EcoleDirecte

L'app consomme l'API non-officielle d'EcoleDirecte. Voici les endpoints principaux utilisés :

⚠ API non officielle
EcoleDirecte ne fournit pas d'API publique documentée. Les endpoints utilisés sont issus de reverse engineering et peuvent changer sans préavis.
POST https://api.ecoledirecte.com/v3/login.awp Authentification

Retourne un token de session (token) à inclure dans les headers de toutes les requêtes suivantes.

Body (form-encoded)

data={"identifiant":"ton_login","motdepasse":"ton_mdp"}

Réponse

{
  "code": 200,
  "token": "abc123...",
  "data": {
    "accounts": [{ "id": 12345, "prenom": "Prénom", "nom": "Nom" }]
  }
}
POST /v3/eleves/{id}/notes.awp Récupérer les notes

Nécessite le header X-Token: <token>.

Headers:
  X-Token: abc123...
  Content-Type: application/x-www-form-urlencoded

Body:
  data={}
POST /v3/eleves/{id}/emploidutemps.awp Récupérer l'emploi du temps

Paramètre dateDebut et dateFin à passer dans le body data.

data={"dateDebut":"2026-03-17","dateFin":"2026-03-21"}

FAQ

Est-ce que l'app est autorisée par EcoleDirecte ?

EcoleDirecte ne fournit pas d'API officielle ni de programme partenaire. L'app utilise les mêmes endpoints que le navigateur, elle ne fait rien de plus que ce que tu ferais manuellement. Utilise-la à ta propre discrétion.

Mes identifiants sont-ils stockés quelque part ?

Les identifiants ne transitent jamais par les serveurs Maxlware. Tout se passe localement sur ta machine : le backend Python envoie directement ta requête à api.ecoledirecte.com. Seul le token de session peut être mis en cache local.

L'app fonctionnera-t-elle si EcoleDirecte change son API ?

Potentiellement non. Puisque l'API n'est pas officielle, EcoleDirecte peut modifier ses endpoints à tout moment. En cas de panne, une mise à jour de l'app sera nécessaire.

Quand sera disponible la première version téléchargeable ?

Pas de date fixée pour le moment. Suis l'avancement sur GitHub ou rejoins le Discord pour être notifié.
