FAQ_

Questions fréquentes sur l'API, le site et les projets Maxlware.

API & Requêtes

Pourquoi est-ce que j'obtiens une erreur CORS ?

L'erreur CORS survient quand ton origine n'est pas autorisée côté serveur. Deux cas courants :

  • Tu utilises credentials: 'include' avec allow_origins=["*"] — ce n'est pas compatible. Il faut lister les origines explicitement.
  • Tu testes depuis un fichier local (file://) — l'origine est "null". Elle doit être ajoutée explicitement dans la config FastAPI.

Solution : utilise plutôt le header Authorization: Bearer <token> sans credentials.

Comment tester l'API en local ?

Utilise curl ou un outil comme Postman/Insomnia pour éviter les contraintes CORS du navigateur :

curl https://api.maxlware.com/v1/com/notification

Si tu veux tester depuis un navigateur, sers ton fichier HTML depuis un serveur local (ex: python -m http.server 8080) plutôt qu'en file://.

L'API retourne une erreur 422, pourquoi ?

L'erreur 422 Unprocessable Entity est émise par FastAPI quand les données envoyées ne correspondent pas au schéma attendu. Vérifie :

  • Que le Content-Type est bien application/json
  • Que tous les champs requis sont présents
  • Que les types de données sont corrects (string, int…)

Le corps de la réponse 422 contient un champ detail qui liste les erreurs précises.

Mon token expire après combien de temps ?

La durée d'expiration dépend de la configuration serveur. En cas d'erreur 401, refais un POST /auth/login pour obtenir un nouveau token et mets à jour ton localStorage.

Site principal

La bannière de notification ne s'affiche pas, pourquoi ?

Deux raisons possibles :

  • La notification est désactivée côté API — actived vaut "false".
  • Tu l'as fermée dans les dernières 24h — le timestamp est stocké dans localStorage sous la clé notificationLastClosed. Supprime-le pour forcer l'affichage : 
    localStorage.removeItem('notificationLastClosed');
C'est quoi l'easter egg du site ?

Tape la séquence a d a m sur ton clavier depuis n'importe quelle page. Un effet visuel (et sonore) se déclenchera. 🎉

Les logos partenaires ne chargent pas.

Les logos sont chargés depuis assets/ en chemin relatif. Assure-toi que les fichiers logo_iptron.png, logo_cloud.png, logo_mxlw_dev.png et logo_galactix.png sont bien présents dans le dossier assets/ à la racine.

Général

Comment contacter Maxlware ?

Plusieurs options :

  • Via le formulaire de contact sur le site
  • Sur Discord
  • Sur Twitter/X
  • Via GitHub
Est-ce que l'API est publique ?

Les endpoints publics (comme /com/notification) sont accessibles sans token. Les routes admin sont réservées à un usage interne. L'API n'est pas ouverte à des tiers pour le moment.

Comment vérifier le statut des services ?

Consulte statuts.maxlware.com pour voir l'état en temps réel de tous les services. Le badge est également affiché en bas du site principal.
