Démarrage rapide_

Fais ton premier appel à l'API Maxlware en moins de 5 minutes.

1. Prérequis

Aucune installation requise pour consommer l'API. Tu as juste besoin de :

  • Un outil pour faire des requêtes HTTP (fetch, curl, Postman, etc.)
  • Une connexion HTTPS (l'API n'accepte pas HTTP)
  • Un token Bearer si tu accèdes aux routes admin
ℹ Base URL
Tous les exemples utilisent https://api.maxlware.com/v1 comme base.

2. Premier appel — Notification

L'endpoint /com/notification est public. C'est le plus simple pour tester :

Avec curl

curl https://api.maxlware.com/v1/com/notification

Avec JavaScript (fetch)

const res = await fetch('https://api.maxlware.com/v1/com/notification');
const data = await res.json();

if (data.actived === "true") {
  console.log("Notification active :", data.message);
}

Avec Python (requests)

import requests

r = requests.get("https://api.maxlware.com/v1/com/notification")
data = r.json()

if data["actived"] == "true":
    print("Notification :", data["message"])

Réponse attendue

{
  "actived": "true",
  "message": "Bienvenue sur Maxlware !",
  "autor": "Maxlware",
  "marker": "verified"
}

3. Routes protégées — Avec authentification

Les routes admin nécessitent un Bearer token. Voici comment l'obtenir puis l'utiliser :

Étape 1 — Login

const res = await fetch('https://api.maxlware.com/v1/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ username: 'admin', password: '••••••' })
});

const { access_token } = await res.json();
localStorage.setItem('token', access_token);

Étape 2 — Appel protégé

const token = localStorage.getItem('token');

const res = await fetch('https://api.maxlware.com/v1/admin/contact/messages', {
  headers: { 'Authorization': `Bearer ${token}` }
});

const messages = await res.json();
console.log(messages);
⚠ CORS & Credentials
Si tu utilises credentials: 'include', ton origine doit être explicitement autorisée côté FastAPI. Utilise plutôt le header Authorization: Bearer qui ne requiert pas de configuration CORS spéciale pour les credentials.

4. Intégrer la bannière de notification

Voici comment reproduire le comportement du site principal pour afficher la bannière de notification :

// 1. Vérifier si la notif a déjà été fermée dans les 24h
function shouldShow() {
  const last = localStorage.getItem('notifClosed');
  if (!last) return true;
  return (Date.now() - new Date(last)) > 86400000; // 24h en ms
}

// 2. Fetch et affichage conditionnel
async function loadNotification() {
  if (!shouldShow()) return;

  const res = await fetch('https://api.maxlware.com/v1/com/notification');
  const data = await res.json();

  if (data.actived === "true") {
    showBanner(data.message, data.marker);
  }
}

// 3. Polling toutes les 5 minutes
loadNotification();
setInterval(loadNotification, 5 * 60 * 1000);
