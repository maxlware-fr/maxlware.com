Projets documentés

L'écosystème Maxlware regroupe plusieurs projets interconnectés :

Projet Statut Description
api.maxlware.com En ligne API centrale — notifications, contacts, authentification.
EcoleDirecte App En cours Client desktop pour EcoleDirecte.
Serveur Minecraft En cours Serveur custom avec plugins.

Stack technique global

Les projets Maxlware sont construits autour des technologies suivantes :

  • Backend — Python (FastAPI), Node.js
  • Frontend — HTML, CSS, JavaScript vanilla
  • Bots — discord.py
  • Infra — VPS Linux, Docker, Nginx
  • Emails — Mailtrap SMTP
